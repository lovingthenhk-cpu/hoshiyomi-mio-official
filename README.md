# 星詠ミオ — Hoshiyomi Mio Official Website

オリジナル架空キャラクター「星詠ミオ」の公式サイトを想定した独立制作プロジェクトです。既存作品や実在する人物とは無関係です。

## デモ
https://lovingthenhk-cpu.github.io/hoshiyomi-mio-official/

## 機能

- 生成画像からアニメ人物セグメンテーションモデルで背景除去したキャラクター・ミニキャラの透明PNGと、周辺透過した天文台画像をCSSと合成
- ニュースのカテゴリーフィルターと拡大可能なギャラリー
- 物語上のイベントを表示する観測カレンダーと日誌詳細モーダル（実イベントではありません）
- 端末の音声合成を利用したセリフ再生（声優の実録音ではありません）
- Web Audio APIで合成するオリジナルアンビエントBGM（操作するまで鳴りません）
- ミオの案内マスコット、お気に入り保存、夜空色とすみれ色のテーマ切替
- ラジオ風の周波数受信UI（87.7 MHzでメッセージ表示）
- 生成素材の髪飾り・望遠鏡・天文台をクリックして見る「ミオの宝物」図鑑
- 3つの結末を集める分岐型の短編ビジュアルノベル（読み終えた結末を保存）
- 七つの星を探す星図ゲームと隠しメッセージ（ブラウザに進捗保存）
- 自分だけの手紙帳（ブラウザのlocalStorageにのみ保存・削除可能）
- PNG壁紙メーカー（モバイル1080×1920、PC1920×1080、正方形1080×1080）
- サイト内検索（Ctrl/⌘+K）、12セクションへのジャンプ、ページ読了バー、先頭に戻る操作
- 好きな呼び名と星・エンディングの収集状況を反映する架空の観測団ファンカードとPNG保存（実会員登録ではありません）
- 台本型キーワード応答チャット（外部AI・サーバー送信なし、会話履歴を残さず消去可能）
- ギャラリー画像のPNG保存、サイトURLのコピー
- PWAホーム画面アイコンと、オフラインで読み返せるキャッシュ機能
- AI生成立ち絵を使用したOG/SNS共有カード、sitemap.xml
- レスポンシブ表示、キーボード操作、低モーション設定を考慮

## 起動

静的HTML/CSS/JavaScriptのみ。ビルドは不要です。

```sh
python3 -m http.server 8000
```

## デプロイ

GitHub Pagesで`main`の`/(root)`を指定して公開します。GitHub Actionsの`workflow`権限は不要です。

## アート制作と注意事項

サイトのキャラクター素材には生成されたサイトモックアップを元に、アニメ画像専用の背景除去モデルで人物輪郭を抽出した透過PNGを使用しています。一部のシーンには周辺フェードを併用しています。背景、情報カード、テキスト、ナビゲーション、波形、星図、壁紙の描画はHTML/CSS/JavaScriptで実装しています。初期バージョンの手描きSVGも`assets/mio.svg`に残しています。

サイトの投稿・イベント情報は架空の演出です。受信メッセージは実際の音声通信ではなく、プログラムで表示する文章です。ユーザーの手紙はサーバーに送信されません。
